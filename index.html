Version 0.3.0

Download for most phones

Works on nearly every Android phone from the last several years (arm64-v8a, ~53 MB)

To install

  1. Tap the download button above.
  2. Open the downloaded file.
  3. Android will ask to allow installs from your browser the first time — allow it, then continue.
Having trouble, or on an older/different device?
  • armeabi-v7a — older 32-bit phones
  • x86_64 — Intel/AMD-based devices, emulators
  • x86 — older Intel-based devices
MYLE1 updates itself after this first install — no need to come back here again.
